# FUTMinna CBT — MVP

Mobile-first CBT study/practice prototype for FUTMinna students (100L–500L).

## Included
- Responsive student-facing landing page
- 100L–500L level selector
- Course selection foundation
- Working practice/exam demo with scoring
- Result screen
- Dashboard/progress placeholder
- Netlify-ready static site

## Production milestones
1. Authorized course/question bank
2. Student authentication
3. Persistent attempts/results
4. Admin question management
5. Full timed CBT engine
6. Analytics and weak-topic recommendations
7. Netlify deployment + production data layer

Academic questions should only be added from authorized sources.
